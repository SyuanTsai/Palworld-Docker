# 共用資料－完整配種表

最後整理：2026-07-26

這個目錄保存可離線查詢的完整配種資料，不必在每次查詢時重新上網。資料只判定兩個親代會產生哪一種子代；被動技能、主動技能、潛力值、突變率與孵化時間不在本表範圍內。

## 資料範圍

| 項目 | 數量／版本 |
|---|---:|
| 適用遊戲版本 | Palworld 1.0／1.0.1 |
| PalCalc 資料庫版本 | v26 |
| 配種計算單位 | 299 |
| 完整配種列 | 44,851 |
| 不分順序親代組合 | 44,850 |
| 同種配種列 | 299 |
| 性別限定列 | 2 |

299 個配種計算單位的所有不分順序組合（包含同種配種）應為：

```text
299 × (299 + 1) ÷ 2 = 44,850
```

完整表有 44,851 列，是因為「闇巫貓＋焰巫狐」依雌雄配置有兩個不同結果，因此同一組物種需要保存兩列。

CSV 使用 UTF-8 BOM，能直接用 Excel 開啟，也能用文字工具或 PowerShell 搜尋。

## 查詢方式

在本目錄開啟 PowerShell：

```powershell
# 已知雙親，查子代
.\查詢配種.ps1 -親代1 金棘獸 -親代2 霄龍

# 已知目標子代，列出所有親代組合
.\查詢配種.ps1 -子代 泰鋒

# 列出某隻帕魯參與的所有配種結果
.\查詢配種.ps1 -單一親代 金棘獸

# 結果很多時只顯示前 20 筆
.\查詢配種.ps1 -子代 泰鋒 -前幾筆 20
```

名稱可使用遊戲繁中名稱、英文名稱或 PalCalc 內部名稱。若系統限制 PowerShell 腳本執行，可改用：

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\查詢配種.ps1 -子代 泰鋒
```

也可以直接用 `rg` 搜尋 CSV：

```powershell
rg '"金棘獸"' 完整配種表.csv
```

## 更新原則

1. 遊戲更新後，先確認是否改動配種資料，不直接覆蓋現有來源。
2. 若要升級資料版本，保存新的固定 commit、原始檔、授權與 SHA-256。
3. 同步修改驗證腳本中的版本、數量與雜湊，再執行腳本。
4. 必須通過來源雜湊、帕魯引用、組合覆蓋、重複列與 CSV 回讀檢查後，才取代現行表。
