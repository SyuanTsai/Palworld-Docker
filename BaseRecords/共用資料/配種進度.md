## 4. 快速 CD 主攻型靈曦龍

- [ ] 目標詞條：神龍＋鬼神＋沈著冷靜＋急性子
- [x] 已有雄性主戰型阿努比斯：不死之身＋金剛之軀＋鬼神＋沈著冷靜
- [x] 已有雌性獄熙龍可作第一條支線親代
- [x] 已有雄性空渦龍：神龍＋傳說＋兇猛
- [x] 使用者確認僅有一隻雄性盜影鴉，且只帶急性子；沒有第二隻盜影鴉
- [ ] 第一波支線 A：阿努比斯（雄性）× 獄熙龍（雌性）→ 靈曦龍
- [ ] 支線 A 保留只有鬼神＋沈著冷靜的靈曦龍，排除不死之身、金剛之軀及獄熙龍親代的雜詞條；性別不限
- [ ] 支線 B：依使用者指定路線，以空渦龍 × 盜影鴉 → 靈曦龍
- [ ] 支線 B 保留只有神龍＋急性子的靈曦龍，排除傳說、兇猛及其他額外詞條
- [ ] 若支線 A、B 的合格靈曦龍性別相反，可直接進入最終波
- [ ] 若支線 A、B 的合格靈曦龍皆為雄性：另行捕獲或取得一隻雌性靈曦龍；這是待取得親代，不列為目前已有
- [ ] 需要轉性的雄性靈曦龍 × 新取得的雌性靈曦龍 → 靈曦龍；保留雌性且維持原支線目標詞條，排除其他額外詞條
- [ ] 最終波：支線 A 靈曦龍（鬼神＋沈著冷靜）× 支線 B 靈曦龍（神龍＋急性子）→ 靈曦龍
- [ ] 最終只保留神龍＋鬼神＋沈著冷靜＋急性子的靈曦龍；性別不限，不保留額外詞條
- [ ] 最終個體濃縮至 4 星，提升夥伴技能的攻擊與移動速度加成

本路線只採用上列已確認親代、使用者之後自行取得的雌性靈曦龍及其子代，不得把其他持有人的帕魯列為可用親代。指定主線為「空渦龍 × 盜影鴉 → 靈曦龍」，不再使用沁蓮龍與昭炎狐回程，也不要求取得第二隻盜影鴉。支線 A、B 若直接取得相反性別，下一波即可完成最終靈曦龍；若兩條支線的合格個體皆為雄性，先以第三隻雌性靈曦龍將其中一條支線轉為雌性，再進行最終配種。沈著冷靜與急性子使主動技能冷卻合計縮短 45%；鬼神提供攻擊 +30%，神龍提供龍屬性攻擊傷害 +30%，定位為搭配噬魂獸擊殺減冷卻效果、連續施放龍屬性範圍技的路邊素材刷怪主攻手。

兩條支線最後各提供兩個目標詞條，直接以靈曦龍互配完成四詞條，不需要其他物種橋接。噬魂獸屬於暗屬性，也能計入靈曦龍的龍／暗屬性隊伍加成。

第四據點有 3 座空置配種牧場，第五據點另有 2 座空置配種牧場，可用最多 5 座牧場執行以下波次。實際搬入前仍以當下存檔配置為準。

| 波次 | 同步配種 | 完成／換場條件 |
|---|---|---|
| 目前 | 燎火舞伶 × 迅雷鳥 → 恐炬靈；趴趴鯰 × 祇岳鹿 → 梆梆鯰；沁蓮龍 × 波霸牛 → 菇咚 | 恐炬靈取得社畜型四詞條；梆梆鯰與菇咚取得吸血鬼型四詞條 |
