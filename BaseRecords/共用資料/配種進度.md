# 共用資料－配種進度

最後更新：2026-07-31

本資料集保存所有據點共用的親代、配種路線與培育進度。實際在哪一個據點進行配種，由各據點依當前名額與牧場空間安排。

完整親代組合、帕魯索引與離線查詢方式統一放在[完整配種表](配種資料/README.md)。本檔只追蹤目前實際培育中的目標與進度，不重複保存全表。

完成的培育目標移至[已完成配種](已完成配種.md)，本檔只保留仍在進行或待處理的項目。

## 1. 快速 CD 移動型靈曦龍

- [ ] 目標詞條：傳說＋沈著冷靜＋急性子
- [x] 已有雄性阿努比斯：不死之身＋金剛之軀＋鬼神＋沈著冷靜
- [x] 已有雌性獄熙龍可作支線 A 親代
- [x] 已有雄性聖光騎士：傳說＋聖天＋急性子
- [x] 已有雌性日耀駒：頑強肉體

2026-07-31 依使用者指定將目標由傷害型四詞條改為移動與冷卻型三詞條，移除神龍與鬼神。沈著冷靜與急性子使主動技能冷卻合計縮短 45%；傳說提供移動速度 +15%，用來兼顧騎乘移動。三詞條已涵蓋本目標需求，不額外加入傷害導向詞條。

兩條支線都能直接產出靈曦龍：支線 A 提供沈著冷靜，支線 B 提供傳說＋急性子，取得相反性別後即可互配完成最終個體。原本用於神龍支線的空渦龍與現有雌性靈曦龍不再是本路線必要親代。

## 2. 4 星撿蛋型笑魘猫

- [x] 已確認本人名下現有笑魘猫僅 1 隻：雌性、1 星、詞條只有認真，目前沒有下一星濃縮進度
- [ ] 最終目標詞條：次元跳躍＋神速＋傳說＋無限精力
- [ ] 優先方案：保留現有雌性笑魘猫，在第五據點的帕魯手術台以植入物替換認真並補齊四個目標詞條
- [ ] 進行手術前先確認本人庫存是否具備所需植入物；四種植入物不齊時，不先消耗現有笑魘猫
- [ ] 備用自然配種第一段：泰鋒（雄性、次元跳躍＋神速＋傳說＋吸血鬼）× 現有笑魘猫（雌性）→ 力士獒
- [ ] 力士獒只保留次元跳躍＋神速＋傳說＋吸血鬼，排除認真與其他額外詞條；性別需與下一段棉悠悠相反
- [ ] 另行捕獲或取得一隻與合格力士獒性別相反、詞條盡量乾淨的棉悠悠
- [ ] 備用自然配種第二段：力士獒 × 棉悠悠 → 笑魘猫
- [ ] 保留次元跳躍＋神速＋傳說＋吸血鬼的笑魘猫；若有無限精力植入物，再以帕魯手術台將吸血鬼替換為無限精力
- [ ] 若沒有無限精力植入物，先停在上述四詞條個體，不開始最終濃縮；之後另建無限精力遺傳支線再合併
- [ ] 最終個體濃縮至 4 星；現有 1 星笑魘猫若直接作為最終個體，依 1.0 的 4／8／12／24 隻素材曲線，尚需 44 隻笑魘猫素材
- [ ] 若改用新生四詞條笑魘猫作為最終個體，可將舊 1 星個體的既有濃縮價值轉入；舊個體等同 5 隻素材，另需準備 43 隻 0 星笑魘猫素材

笑魘猫定位為撿蛋用高速坐騎，而非主戰個體。次元跳躍、神速與傳說提高移動速度，無限精力提高騎乘續航；濃縮至 4 星後，夥伴技能的額外取得帕魯蛋機率由 1 星的 55% 提升至 75%。詞條完成後，持續使用「力士獒 × 棉悠悠 → 笑魘猫」量產濃縮素材；素材個體不要求詞條或性別。

本路線只使用本人名下已確認的雌性笑魘猫、雄性泰鋒，以及之後自行捕獲或取得的棉悠悠與其子代，不得將其他持有人的帕魯列為可用親代。若已有四種目標植入物，優先手術保留原本的雌性 1 星笑魘猫，可少做兩段詞條轉移；若只具備無限精力植入物，則採自然配種備用線，把手術需求降為一次。若連無限精力植入物也沒有，先完成並保留吸血鬼版本，不投入最終濃縮。
