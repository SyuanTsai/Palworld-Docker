## 維護規則

1. 共用公式或培育結論只在共用子資料集維護一次。
2. 據點檔案只記錄該據點採用的數量、配置與共用規則的例外。
3. 據點若採用不同配置，需在據點檔案寫明覆寫原因，不直接修改共用基準。
4. 新增據點時，先建立新的據點檔案，再引用需要的共用子資料集。
